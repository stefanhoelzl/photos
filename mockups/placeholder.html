Photo album viewer — UI mockups

Synthetic placeholder tiles and generic album names — the committed variant, carrying no personal photos.

Layout and content, not chrome. These were drawn before §6 settled on Compose Multiplatform with Material 3; what they fix is what is on each screen and how it is reached, not the shape of a button.

Both colour schemes are the app’s — it follows the system theme and has no appearance setting. The toggle above exists only on this sheet, so both can be reviewed without changing the OS. Media stays on black in either scheme, and so does any chrome sitting on a photograph.

Illustrative library: 239 top-level albums · 288 leaf albums · ~33.5k photos · 550 videos · ~120 GB · ~25% GPS-tagged · 187 Live Photos

Revised by the milestone-E design interview. Every screen carries the milestone that builds it — E.1 the read-only app on Linux, E.2 offline albums, E.3 iOS, F map, G upload — and these decisions changed what is drawn:
  • Images download on two triggers only (E.2) — opening an album, or asking for it on the list. Leaving an album stops its download; nothing is ever auto-evicted. §6's browse-to-cache is replaced, and with it the line saying there is no way to prepare for a flight
  • One list, not two — the cache controls live on the album list itself, so Settings keeps only account, storage totals, sync and log out. Containers aggregate their children
  • One strip on the right edge is the progress bar — grey nothing held · part blue this much held · part blue pulsing and moving now · full green the whole album is offline. That is the entire cache vocabulary, and it replaced a gauge plus a line of prose on every row: the caption is back to naming the album's contents
  • Swipe-left reveals icon-only actions, and tapping the strip does the same — the strip's hit area is grown to 44pt without growing the mark, so the actions have a route that is not a gesture. Swipe-right is unused because it collides with the interactive back gesture. Clear also pauses, and needs no confirmation
  • Gold is retired: blue replaces it — green = start work, blue = active state (the set-as-cover star, and pause), red = destructive. Colour still carries meaning and never decorates
  • 2-column density draws the cached 3200px image when one is on disk, upscaled pack thumb otherwise — the grid still never asks for a blob, so it stays a local read that works offline
  • Every album's thumbnail pack is fetched in the background after the shards; a photograph that has not arrived is drawn as a photograph-shaped mark, pulsing only while a worker is on it — the same rule the strip uses, so motion means one thing everywhere in the app
  • Sort is one icon that cycles date↓ → date↑ → name; the subtitle already names the state
  • Errors are a toast naming status and cause, with duration by kind — a 403 waits for you, a dropped network clears itself; the Settings sync row is the durable record
  • Set-as-cover moved to G, making E read-only in fact; share moved to E.3, being platform interop
